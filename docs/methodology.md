# Методика исследования

## Исследовательский вопрос

Как различаются показатели производительности веб-приложения MicroBlog при переходе от базовой загрузки JPEG к комплексным стратегиям WebP + lazy loading и AVIF/WebP/JPEG + адаптивные изображения?

## Дизайн

Объект: микроблог с девятью изображениями; три версии HTML/CSS, одинаковый основной интерфейс. Исторические замеры проведены для мобильного профиля браузера Chromium/Chrome, десять измерений для каждой версии. Исходная методика и результаты приведены в отчёте НИР, этап 2.

**Метрики:** LCP (секунды), FCP (секунды), TBT (миллисекунды), CLS (безразмерная величина), Speed Index (секунды), Performance Score (баллы).

**Важно:** сравнение не изолирует влияние отдельных переменных: меняются формат, lazy loading, декодирование и адаптивность. Для последующей ВКР нужен факторный эксперимент, стабилизация сетевых условий, рандомизация и A/A-тест.

## Конвейер публикации

1. `data/historical_measurements.csv` хранит сводные опубликованные значения.
2. `scripts/generate_results.py` читает CSV, проверяет значения, создаёт график и Markdown-таблицу.
3. MkDocs собирает сайт из `docs/`.
4. GitHub Actions выполняет генерацию, строгую сборку и публикацию на GitHub Pages.
5. Дополнительно возможна публикация на Helios через отдельную SSH-задачу (требует настройки секретов).

Сайт не пересчитывает первичные экспериментальные значения и явно указывает происхождение данных.
