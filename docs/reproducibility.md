# Воспроизводимость публикации

## Локальная сборка

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/generate_results.py
mkdocs build --strict
mkdocs serve
```

## Обновление данных

Измените числовые значения в `data/historical_measurements.csv`. После запуска генератора Markdown, CSV-хеш и график будут обновлены. Если исходные данные не изменились, генератор использует кэш (сверка SHA-256 файла, кода генератора и версии графической библиотеки). Для проверки кэша запустите скрипт дважды.

## Версия данных и кода

Внизу страницы результатов отображаются SHA-256 данных и хеш Git-коммита (если репозиторий инициализирован). Это фиксирует связь опубликованной страницы с исходным состоянием.

## Научные ограничения

Имеются только сводные значения прошлого исследования. Они не заменяют сырые измерения. Для воспроизведения **эксперимента**, а не только публикации, потребуются контейнеризированный стенд и новые прогоны по плану ПР4.

## Метаданные публикации

См. [метаданные сборки](build-info.md): время сборки UTC, git SHA, версия и SHA-256 набора данных. Эти данные создаются каждый раз, в том числе при попадании в кэш.
