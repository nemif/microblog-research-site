# Исследование производительности загрузки изображений

**Автор:** Фотеев Иван Алексеевич, ИТМО, программа «Веб-технологии».

Этот сайт публикует результаты учебного исследования по теме «Исследование производительности современных подходов к оптимизации загрузки медиа-контента».

Объект — тестовое веб-приложение MicroBlog с тремя вариантами доставки изображений:

| Вариант | Метод | Описание |
| --- | --- | --- |
| v1 | JPEG baseline | Девять изображений JPEG, без lazy loading и адаптивных источников |
| v2 | WebP + lazy | WebP с JPEG fallback, отложенная загрузка, `decoding=async` |
| v3 | AVIF / WebP / JPEG + `srcset` | Адаптивные изображения и отложенная загрузка |

Результаты ниже воспроизводят **исторические измерения, описанные во втором этапе НИР**, а не результаты нового контейнеризированного эксперимента. Три варианта различаются несколькими факторами одновременно; это ограничивает причинную интерпретацию.
